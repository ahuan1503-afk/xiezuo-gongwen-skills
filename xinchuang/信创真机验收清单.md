## 一、离线包完整性与安全边界

- [ ] **完整性校验**：解压离线包后运行 `sha256sum -c SHA256SUMS.txt`，全部文件显示 `OK`。
- [ ] **安全报告核对**：打开根目录《安全自查报告.md》，确认为「通过（0 项违规）」。
- [ ] **无商用字体二进制**：确认包内不含 `.ttf`/`.otf`/`.ttc` 字体文件。
- [ ] **回环监听验证**：启动工具箱后执行 `ss -lntp | grep 8765`，仅监听 `127.0.0.1`，断网可正常运行。

## 二、零命令行启动与本机工具箱

- [ ] **双击启动**：在文件管理器双击 `xinchuang/启动工具箱.sh`（或 `.desktop`），自动弹出国产浏览器打开工具箱首页；如端口 8765 被占用，自动顺延到 8766+。
- [ ] **一键复制提示词**：顶部下拉能看到 4 套「一站式合集」和 22 份「单技能精简」，点「复制所选提示词」可成功粘贴到记事本或内网模型网页。
- [ ] **导入 `.docx` 文件**：左框点「导入 .docx/.txt/.md」，选一份普通 Word 文档，正文和表格文字正确读入（无需安装 `python-docx`）。
- [ ] **涉密强拦截**：左框输入含 `机密★5年` 或 `内部资料` 的测试句（或导入页眉带保密标识的 `.docx`），点「② 脱敏」被强拦截并提示停止处理。
- [ ] **脱敏与还原闭环**：左框输入含假手机号 `13812345678` 和自定义词 `张三` 的普通通知，脱敏 → 复制到右框 → 点「③ 还原」，还原后与原文一致；开两个浏览器标签页互不覆盖映射表；点「清空本页映射表」后无法再还原。
- [ ] **八关机检与事实核对**：右框点「④ 八关机检」出 P0/P1/P2 清单；改动右框一个数字后点「⑤ 事实数字核对」能报出差异。

## 三、字体与三种排版兜底路径（按本机条件勾选其一即可）

- [ ] **路径 1（本机工具箱一键排版）**：
  - 点「⑥ 本机字体自检」，缺字时如实报缺（不回退），本单位规定方正 GBK 字体族时切换下拉「方正 GBK 字体族」复测。
  - 点「⑦ 国标排版」下载 `成稿.docx`：有 `python-docx` 时走完整模式；**无 `python-docx`（含龙芯机器）时自动切到纯标准库轻量排版**，下载的 `.docx` 可在 WPS / 永中正常打开。
- [ ] **路径 2（免 Python、免宏空白模板）**：
  - 直接用 WPS / 永中打开 `xinchuang/templates/01-白头公文模板.docx` 和 `02-红头公文模板.docx`，粘贴一段纯文本（「只保留文本」），检查纸张 A4、边距 37/35/28/26 mm、22 行×28 字网格、奇偶页页码是否保持不变。
- [ ] **路径 3（WPS JS 宏，仅当单位未禁用宏时测）**：
  - 打开 WPS 文字 → 开发工具 → WPS 宏编辑器 → 粘贴 `skills/gongwen-format/assets/wps_gongwen_macro.js` → 运行 `GongwenFormat`；记录弹窗是否提示有失败步骤，并核对一级/二级标题字体与行距。

## 四、OFD 导出与打印样张核对

- [ ] **导出 OFD 并体检**：在 WPS / 永中将成稿导出为 `.ofd`，在工具箱点「⑧ OFD 结构体检」上传（或命令行跑 `python3 skills/gongwen-format/scripts/ofd_check.py 成稿.ofd`），确认页面 `210×297 mm`、无思源/Noto/文泉驿等 Linux 默认回退字体。
- [ ] **阅读器与实纸打印**：用数科 / 福昕 / WPS OFD 阅读器打开并打印 1 份样张，肉眼核对：
  - [ ] 每页 22 行、每行 28 字，末页落款未成孤页；
  - [ ] 红头与红色分隔线居中、无断线偏移；
  - [ ] 奇偶页页码分别为右空一字 / 左空一字、四号宋体一字线；
  - [ ] 印章留白足够，不遮挡末行正文。

## 五、内网大模型与知识库（如单位已部署）

- [ ] **知识库导入**：按 `dist/rag-kb/README.md` 将切片导入 Dify / MaxKB / FastGPT / 扣子开源版，搜索测试「请示和函的区别」「GB/T 9704 页边距」均能命中带 `[知识来源]` 锚点的条款。
- [ ] **国产模型防线抽测**：运行 `python3 evals/xinchuang/smoke_eval.py --base-url <内网模型地址> --model <模型名>`（详见 `evals/xinchuang/README.md`），确认涉密拦截、防编造、纯文本输出、脱敏占位符保留四条底线全部通过。
