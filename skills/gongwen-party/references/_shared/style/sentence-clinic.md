# 公文句子诊所与节奏对照库

抽象的“像公文”“不要太碎”很难落地，本文件用**同一意思的正反句对照**，解决 AI 起草公文最常见的四类文风病：句长塌陷、并列失衡、力度词超标、标点修辞化。

> **红线提示**：所有“成稿版”示范的是**把用户已有信息组织进长短结合的公文句式**，严禁为了拉长句子、凑顿号而编造用户材料里没有的事项、数字或单位。

## 一、先判偏离方向：不是并列越多越像公文

AI 起草公文时，偏离方向因文种分成截然相反的两侧，动手前先判自己在那一侧：

```text
分析类、叙事类（调研报告 / 领导讲话 / 工作总结 / 经验材料 / 千字基层短材料 / 情况报告）
  → 容易“并列不足、句长偏短、顿号偏疏、动作虚化” → 往下看第二节（补信息挂接）

规范性部署类（工作意见 / 工作方案 / 实施方案 / 部署通知）
  → 容易“并列过度、每条像器材清单、顿号顶破、‘不得’泛滥” → 往下看第三节（拆并列、控强制词）
```

## 二、分析与叙事类：怎么把碎短句立起来

### （一）工作总结 / 经验总结
招牌句式：**“围绕/坚持……，通过 A、B、C，确保……”**。注意：回顾性总结的要求力度多落脚在**“确保 + 结果”**，而不是向下下命令式的“要”。

- **偏离版（碎短、空泛）**：
  > 去年以来，我镇推进农村人居环境整治。重点抓了三方面工作。一是清垃圾，二是治污水，三是建管护机制。目的是让环境长久保持干净。
- **成稿版（信息密实、一气呵成）**：
  > 去年以来，我镇把生活垃圾清运、沟渠水体治理和日常长效管护统筹谋划、同步推进，划片落实镇包村、村包组、党员包户三级责任，确保主干道、背街小巷和房前屋后同步整治到位、不反弹。
- **差在哪**：把四句碎话收进一句有主干的长句里，把空泛的“建立机制”落到具体的“三级责任”和“确保不反弹”。

### （二）调研报告
招牌特点：**导语句用并列亮出后文纲目**；分析段用平行短语说透商业/行政机制；对策段必须把“要/建议”挂在**具体主体 + 具体筛选标准**上。

- **偏离版（空洞判断，无路标）**：
  > 表面看是企业不愿改。深究下去，其实是我们配套工作存在明显缺口。
- **成稿版（路标清晰，直指机制）**：
  > 表面看是企业观望顾虑，深究下去，反映出我们在场景供给、成本分担、技术人才和标准衔接四个环节仍有短板。
- **偏离版（建议虚飘，动作没落点）**：
  > 建议工信部门会同行业协会选好试点，明确考核指标，推动企业改造。
- **成稿版（主体、对象、标准一体落地）**：
  > 建议由区经信局牵头，会同行业协会深入车间选题，优先在质检、排产、设备巡检等工序清晰、数据可采的环节开展试点，逐项明确改造前后的可测指标。

### （三）经验材料（长版）
经验材料的并列承担的是**“让外单位能照着抄的操作清单”**，不是修辞装饰。

- **偏离版（抽象概括，学不到做法）**：
  > 我们与多个部门签了共享协议，明确了安全要求，很快打通了数据。
- **成稿版（要素具象，可复制）**：
  > 我局牵头与民政、人社、卫健等部门签署数据共享备忘录，逐项写明调取字段、使用用途、留存期限和泄密责任，仅调用业务认定必需项，打通了跨部门核验堵点。

### （四）领导讲话
讲话稿最怕两种极端：一种写成“文件的朗读版”（满篇 80 字长定语，喘不过气）；另一种通篇二三十字干巴祈使句（像冷冰冰发指令，不像在会上跟人说话）。好讲话是**“具体画面并列 + 短句发力落点”**。

- **偏离版（干巴口号，听不出重点）**：
  > 要坚持一户一策。把各个环节衔接好。坚决不能推诿空转。
- **成稿版（有现场感、长短错落）**：
  > 要坚持一户一策，把选址、审图、施工、验收四个环节一次交底，决不允许再出现边等方案、边等资金、边等队伍的空转。群众过冬的事，一天都不能含糊。
- **差在哪**：前句用四项环节与三项“边等”把空转画实，末句用 17 字短句收口发力——**短句少而精，出现时才有穿透力**。

### （五）千字级基层 / 党建短经验材料
这类材料零一级标题，靠**具体主体 + 具体物件枚举 + 一线原话（限用户材料提供）**撑出实感，把枚举换成“必要设备”“多方协调”就会瞬间变水。

- **偏离版（笼统变水）**：
  > 街道盘活闲置场地建了服务驿站，配齐了必要设施，还组织多方协调解决了骑手停车充电难题。
- **成稿版（画面具体、顿号承载信息）**：
  > 街道统筹党群服务中心、社区服务站和物业闲置用房，改造建设暖心驿站，配齐饮水机、微波炉、充电插座、应急药箱；把物业、商圈管理方和站点负责人请到一张桌上商量，在小区门口划出临时停放区、加装共享充电柜，方便骑手歇脚充电。

## 三、规范性部署类：怎么砍掉过度并列

工作意见、工作方案、部署通知每一条都是要求，如果每条都塞 5～7 项顿号枚举，不仅顿号密度失控，读者也抓不住重点。**正确砍法不是切成碎句，而是保留最关键的 2～3 项，或把长枚举拆成并列分句**（反而稳住句长）。

### （一）工作意见：删冗余修饰枚举
- **过度版（6 项并列，主次不分）**：
  > 岗位设置要综合考虑社区实际工作量、人口结构、服务半径、财政承受能力、历史沿革、居民诉求，不搞层层摊派、不下达硬性指标、不简单比照外地、不脱离本地实际。
- **定稿版（保留最能界定边界的核心项）**：
  > 岗位设置要结合社区实际工作量、人口结构和服务半径统筹核定，不搞层层摊派，不下达硬性指标。

### （二）工作方案：用分句替代器材清单式顿号
- **过度版（顿号扎堆，像采购清单）**：
  > 条件具备的小区新建集中停放棚，同步配置照明、监控、灭火器材、自动断电装置、消防水源和警示标识。
- **定稿版（保留主干 + 分句归拢）**：
  > 条件具备的小区新建集中停放棚，同步配齐照明和视频监控，并按消防技术标准落实灭火与断电保护设施。

## 四、强制词配额替代表（不弱语气、不破配额）

规范性文件和改稿时最容易把“不得”“必须”“严禁”一路堆到七八处。全篇只把强制词留给**真正不可突破的红线条款**，其余改用精准动作词，力度一点不减：

| 过密写法 | 推荐替换（语气同样坚决） |
|---|---|
| 与职责无关的报表**不得**下派 | 与职责无关的报表**一律取消** |
| 未经审批**不得**擅自调整预算 | 未经审批**不予**调整预算 / **严控**无预算调整 |
| 逾期未整改的**必须**追责 | 逾期未整改的，**依规依纪**问责 |
| 各单位**必须**在周五前报送 | 各单位**要**于【具体日期】前报送 |
| **严禁**以拍照留痕代替实地核查 | **坚决防止**以拍照留痕代替实地核查 / **不将**拍照留痕作为验收依据 |

## 五、公文标点去修辞铁律

公文标点是语法边界件，不是自媒体节奏特效：
1. **破折号（——）**：除主副标题（副标题前用破折号）外，正文全篇尽量 **0 处，最多不超过 1 处**。需要停顿用逗号，需要转折或强调直接用句号断开。
2. **冒号（：）**：正文原则上只用于**主送机关后**（各科室：）、**引语引入**（会议指出：）、**总起分条**（现将有关事项通知如下：“存在的主要问题是：”），以及时间、地点、联系人等**字段标签**（与机检白名单 WL-004、WL-006、WL-007、WL-017 一致）。避免自媒体式悬念冒号（把“关键在于：”“做法是：”改为“关键在于，”“具体做法是，”或直接陈述）。
3. **禁用元评论拐杖**：删去“其实是”“说到底”“归根到底”“值得注意的是”“需要指出的是”，直接把结论说出来。讲话稿口语化可少量保留“说到底”（全篇一两处，见 `ai-tone.md` 讲话稿放宽条款），“值得注意的是”仍不用。
4. **中文弯引号规范**：中文引号统一用全角弯引号“ ”和‘ ’，不在中文正文中混用英文直引号 `"`。
