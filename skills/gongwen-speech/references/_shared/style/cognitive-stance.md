# 公文站位、分寸与认知框架

本文件补齐“写得准、写得稳、像体制内老手写的”隐性认知层。红线（保密、防编造、正文干净）始终优先于本文件；本文只管**站位高度、归因分寸、敏感降压、具名梯度与党建业务挂接**，不新增任何用户未提供的事实。

## 一、开篇站位：按行文方向与机关位阶选切入点

切入点不是固定套话，而是由**行文方向 × 发文机关位阶 × 文种功能**决定：

| 场景 / 文种 | 推荐站位 | 写法要点 | 避坑 |
|---|---|---|---|
| **工作意见 / 规范性下行文**（立规矩） | 战略定位 + 授权依据 | 先挂上级部署或全局目标，再用一句判断把本领域嵌进去，交代“为什么必须立规矩” | 忌直接从“本单位存在很多毛病”切入 |
| **受命调研 / 专项督查报告**（上行） | 授权与方法学前置 | 首段交代谁部署、何时、赴何处、走访了哪些对象和样本量（均取自用户材料），先立可信度 | 忌先扣大帽子却不交代调研怎么做的 |
| **自身即权威机关的常规通知 / 批复 / 函** | 极简直陈 | 省去宏观帽子，直接写来文、目的或政策脉络，一两句进入正题 | 忌 400 字通知配 200 字空泛背景 |
| **经验材料 / 交流发言**（陈述本单位做法） | 时间背景直陈或问题破题 | 直接交代“近年来，某单位围绕……探索出……”，或以“过去曾经遇到的已解决痛点”破题 | 忌长篇大论讲全国大势、套用“在……正确领导下”空壳 |
| **面向基层的领导讲话（座谈/观摩/动员）** | 场景切入 / 同场共情 | 结合会议现场、时令或一线真实现象开场，先把听众拉回会场 | 忌把讲话写成“文件的朗读版” |

**站位铁律（上行与分析类长文）**：
- **批评机制或指出深层短板前，先垫成效与大局**。直接拿制度缺陷做全文第一句，在体制内会被视为站位偏颇、情绪化；先客观肯定基础成效，再以“但也要看到”“对照更高标准”转入问题，批评才立得住。
- **不替自己造“假授权”**：上级文件、领导批示只用用户材料里真实存在的；没有就不硬挂，直接从本单位职责和实际需求起笔。

## 二、归因分寸与四档力度词

### （一）成绩与问题的归因分工

- **写成绩**：把功劳适度往外、往上归（依托政策支持、各方协同、一线干部群众实干），具体做法和成效数据落到本单位实干上，不居功自傲、不自我拔高。
- **写问题（按性质分流）**：
  1. **客观制约类**（地理条件、历史欠账、发展阶段、跨区域外部因素）：用于说明困难的长期性和复杂性，不胡乱点名归责。
  2. **工作与认识类**（思想重视不够、推进不够均衡、机制衔接有堵点）：必须加限定范围（“少数”“部分”“个别环节”），把整改责任收进**本级能兑现的职权边界**内；不把本级解决不了的体制问题写成自己能包办的承诺。
  3. **多因复合类**：复杂调研问题用“既有历史遗留，也有当下衔接不畅；既有客观条件限制，也有工作落实不够到位”做稳妥过渡。

### （二）力度词按对象与文种精确分层

公文的主体语气是**“要求”**，不是满篇“必须/严禁”：

| 力度档位 | 典型词 | 适用对象与文种 | 配额提醒 |
|---|---|---|---|
| **强制级** | 必须、务必、不得、严禁 | 规范性文件红线条款、底线纪律、客观必要前提 | **稀缺资源**：四个词共用一份配额（与机检 DEF-028 同一词表），普通 3000 字部署稿写作时通常控制在 0～4 处；机检阈值为每千字 3 处（函、批复 6，讲话类 4.5，信息、简报、总结类 2）。“应当”是制度条款、法定职责的规范性义务用语，按需使用，不占配额；“一律取消”“不予办理”属于取消类动作写法，也不占配额 |
| **要求级** | 要、切实、确保、抓好、落实 | 下行文、领导讲话、方案、意见的主力动词 | 下行部署靠“要 + 具体动作”；回顾性经验总结靠“确保 + 落地结果”而非“要” |
| **建议级** | 建议、可、鼓励、支持、探索 | 上行调研报告、请示中的工作思路、非强制倡导条款 | **上行建言专用**；有权下令的部门通知里不用“建议” |
| **期望级** | 希望、力争、争取 | 领导讲话结尾号召、面向非直属对象（如群众、协办单位、企业） | 正式规范性文件中几乎不用“希望” |

**对象辨析示例**：同一篇领导讲话中，对本系统直属部门说“要按期完成”，对无隶属关系的配合单位或基层群众说“希望继续大力支持”“请积极配合”。

## 三、敏感问题与部门分歧的六种降压写法

在调研报告、情况报告、推进会讲话中，遇到“必须指出真问题、又不能写成情绪指控或越权指责”的场景，采用以下六种稳妥技法（所有事实仍须严格来自用户材料）：

1. **部门分歧转述为业务/标准口径差异**：如实呈现双方关切（一方重效率、一方重安全合规），归因于“标准衔接不够、协同机制尚未打通”，不把利益猜测写成定论；若材料确有反映，用“部分受访单位反映”保持转述距离。
2. **把敏感批评抽象为现象通例**：指出共性作风或推诿问题时，除用户明确点名的通报案件外，改用“一些地方”“有的单位”“少数环节”归纳规律，对事不对人。
3. **重判断挂在外部事实或数据落差上**：不用情绪形容词骂“流于形式”，直接摆材料里的数据落差（如覆盖率高但实际使用率低、群众多次往返）或原话，让事实自己下结论。
4. **先自我认领，再向下压责**：领导讲话批评落实不力时，先表态“我作为第一责任人先认领责任、先从本级查起”，再对各部门提硬要求，更容易被接受。
5. **敏感议题主动自设边界**：谈信息公开、放权让利、容错纠错等敏感建议时，紧跟一句底线边界（如“在严守保密纪律和安全底线前提下”“严格履行审批程序”），避免被误读为失管。
6. **按文种控制转折密度**：调研报告、推进会讲话需要“先扬后抑”讲透问题，可合理用转折；纯报喜的经验交流、表扬通报和立规矩的工作意见，不硬加“存在的不足”或生硬转折。

## 四、案例具名与脱敏四级梯度

在遵守隐私与保密红线的前提下，按案例性质把握具名精度：

| 案例类型 | 具名方式 | 适用理由 |
|---|---|---|
| **正面典型与可复制做法** | 单位名称、机制名称、成效数字按用户材料写全 | 便于其他单位对标学习、可复制 |
| **已公开通报处理的反面案例** | 仅按公开通报口径，已免职的须带“原”字（如“原某局负责同志某某一案”） | 已有定性，不越界定案 |
| **内部核查/尚未公开的问题事例** | 单位降到通名或处室级，人名脱敏为“某某一”或职务，**关键金额/次数/天数按材料精确保留** | 可核查性留在数字上，涉密与名誉风险从人名上卸掉 |
| **普通群众、患者、学生、信访人** | 一律脱敏（如“某小区居民”“张某”），隐去身份证号、手机号、住址、病案号、学号 | 保护个人隐私，符合保密与合规红线 |

## 五、党建与基层经验材料的特殊规律

写党建经验材料、国企/医院/高校党建业务融合材料及千字级基层治理经验时，不要生搬硬套 3500 字机关部署文件路子：

### （一）千字级基层/党建短经验 vs 三千字公文长文（两族互斥）
- **千字短经验（约 900～1400 字）**：通常**不设“一、二、三、”一级大标题**，靠 5～6 个自然段 + 段首动宾提领句（如“建强网格阵地，把服务送到家门口。”）推进，多用用户材料中的具体物件、具体场景与一线原话，少下指令（要求词极少）。硬塞三四个一级标题会把千字好材料切成“压缩饼干式八股文”。
- **三千字以上党建调研/工作报告/方案**：结构走对应公文长文骨架，只借用本节的党建业务挂接逻辑。

### （二）党建与业务融合的七种挂接逻辑
写党建经验的核心难题是避免“两张皮”（把业务成绩硬贴党建标签）。优先从用户材料中提炼对应的因果挂接方式：
1. **支部建在业务单元上（物理嵌入，说服力最强）**：把党组织设在项目工地、产业链、网格、临床一线，直接说明组织怎么嵌入业务流程。
2. **量化考核联动（机制绑定）**：党建考核与经营/绩效指标挂钩、联动计分，用制度刚性说明党建不空转。
3. **骨干/队伍中介式**：党建带队伍（党员先锋岗、技术攻关队、导师带徒）→ 队伍破业务难题。
4. **优势转化式（国企/机关高频）**：把政治优势、组织优势转化为攻坚能力、服务效能、核心竞争力。
5. **融合一盘棋式**：思想同向、组织同步、考核同责，破解“两张皮”。
6. **“党建+具体业务”命名式**：围绕核心痛点打造具体载体，落到可检验的实事清单。
7. **实践收束判断式（慎用，只放末段）**：在充分事实支撑后，收束为“党建做实了就是生产力、做强了就是竞争力、做细了就是凝聚力”。

### （三）两条易错实务规律
- **经验材料不硬凑“本单位未解决的短板”**：纯经验交流材料聚焦已验证的成熟做法；可以写**推进初期遇到但已经克服的思想阻力或客观难题**（如“起初部分同志有畏难情绪、群众有顾虑，通过……化解”），这比只夸成绩更真实可信，但不要主动增设“当前存在的不足”一节（那是工作总结和调研报告的板块）。
- **引用服从论证需求，不强行凑数**：基层单位讲自己做成的一件实事，事实本身就是依据；用户未提供高层论述或上级文件原文时，不强行硬塞“政治帽子”，更不凭记忆补写引文。
