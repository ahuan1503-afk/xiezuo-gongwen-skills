# 过程记录：E　高校活页匿名形式审查（只审不写）

> 演示行业包 `gongwen-university` 的申报书匿名形式审查：严守“辅助不代笔”，只查身份暴露与形式问题，不代写学术论证。所有姓名、单位、批准号均为虚构。

## 第一步　对活页初稿执行本机匿名机检

```bash
python skills/gongwen-university/scripts/proposal_check.py 输入-国社科活页初稿.txt --blind --names 赵明辉,华东大学 --strict
```

初检结果见 `1-活页匿名机检报告.txt`（退出码 `1`）：
- **P0 1 条**：直接出现申请人姓名（输出自动遮蔽为 `〔身份词〕`，不回显真实姓名）；
- **P1 5 条**：自称“笔者”“本人”“我校”、项目批准号（`20CSH048`）、电子邮箱；
- **P2 2 条**：前期成果自述（主持课题、出版专著《……》）。

## 第二步　申请人按审查意见修改活页

删去联系人、邮箱、批准号与专著自述，将“笔者”“本人”“我校课题组”改为客观学术表述（“既有研究”“前期已有学者”“基于东部三个样本县的田野访谈资料”），形成 `2-修改后活页定稿.txt`。

## 第三步　复检验证

```bash
python skills/gongwen-university/scripts/proposal_check.py 2-修改后活页定稿.txt --blind --names 赵明辉,华东大学 --strict
```

复检结果见 `3-复检报告.txt`（退出码 `0`）：**P0 0 条、P1 0 条、P2 0 条**。
